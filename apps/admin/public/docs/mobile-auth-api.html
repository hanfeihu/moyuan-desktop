墨渊 App 用户登录注册接口文档

本文档给手机 App 端使用，覆盖邮箱验证码、用户注册、用户登录、当前用户查询和 Token 鉴权约定。 管理员后台接口不在本文档范围内。

当前生产 Base URL http://codex.tminos.com:18080/admin-api
请求格式 Content-Type: application/json
更新时间 2026-06-01

接入流程

  1. 用户输入邮箱，App 调用 POST /auth/send-code 发送验证码。
  2. 新用户调用 POST /auth/register，已有用户调用 POST /auth/login。
  3. 登录或注册成功后，App 安全保存响应里的 token。
  4. 后续需要登录态的接口统一携带 Authorization: Bearer <token>。
  5. App 启动、恢复前台或遇到鉴权疑问时，可调用 GET /me 校验登录态。

Token 鉴权规则

推荐请求头 Authorization: Bearer <token>
兼容请求头 x-moyuan-auth-token: <token>
默认有效期 30 天

Token 只在登录或注册成功时返回。Token 缺失、错误、过期或账号停用时，接口返回 401。

接口列表

POST /auth/send-code

给用户邮箱发送验证码。验证码有效期 10 分钟。

email必填，用户邮箱地址。

请求示例

{
  "email": "user@example.com"
}

成功响应

{
  "data": {
    "sent": true,
    "expiresIn": 600
  }
}
POST /auth/register

注册用户并直接登录。邮箱已存在时，会更新姓名、激活账号并返回新的登录 Token。

email必填，用户邮箱地址。
code必填，邮箱验证码。
name可选，用户显示名称；不传时使用邮箱前缀。

请求示例

{
  "email": "user@example.com",
  "code": "123456",
  "name": "张三"
}

成功响应

{
  "data": {
    "token": "session-token",
    "user": {
      "id": "user-id",
      "email": "user@example.com",
      "name": "张三",
      "status": "active",
      "tokenBudget": 0,
      "tokenUsed": 0,
      "promptTokens": 0,
      "completionTokens": 0,
      "skillTokens": 0,
      "createdAt": "2026-06-01T00:00:00.000Z",
      "lastLoginAt": "2026-06-01T00:00:00.000Z"
    }
  }
}
POST /auth/login

使用邮箱验证码登录已有账号，成功响应结构与注册接口一致。

email必填，用户邮箱地址。
code必填，邮箱验证码。

请求示例

{
  "email": "user@example.com",
  "code": "123456"
}

成功响应

{
  "data": {
    "token": "session-token",
    "user": {
      "id": "user-id",
      "email": "user@example.com",
      "name": "张三",
      "status": "active",
      "tokenBudget": 10000000,
      "tokenUsed": 0,
      "promptTokens": 0,
      "completionTokens": 0,
      "skillTokens": 0,
      "createdAt": "2026-06-01T00:00:00.000Z",
      "lastLoginAt": "2026-06-01T00:00:00.000Z"
    }
  }
}
GET /me

获取当前登录用户信息。App 可用它判断本地 Token 是否仍然有效。

请求头

Authorization: Bearer session-token

成功响应

{
  "data": {
    "user": {
      "id": "user-id",
      "email": "user@example.com",
      "name": "张三",
      "status": "active",
      "tokenBudget": 10000000,
      "tokenUsed": 1200,
      "promptTokens": 500,
      "completionTokens": 300,
      "skillTokens": 400,
      "createdAt": "2026-06-01T00:00:00.000Z",
      "lastLoginAt": "2026-06-01T00:00:00.000Z"
    }
  }
}

错误响应

所有错误统一返回 JSON。App 应优先展示 error 字段里的中文提示。

400请求参数不完整或格式错误。
401未登录、Token 失效、验证码错误或账号不可用。
404账号不存在，请先注册。
500邮件服务、数据库或服务端异常。

示例

{ "error": "验证码不正确或已过期" }

App 端建议

  • 验证码发送成功后再进入倒计时，不要在接口失败时显示“已发送”。
  • 登录 Token 建议保存在系统安全存储中，退出登录时主动清除。
  • 遇到 401 时清除本地 Token，并引导用户重新获取验证码登录。
  • 用户额度字段以服务端返回为准，App 不要在本地自行推算最终余额。
